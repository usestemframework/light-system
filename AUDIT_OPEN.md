## Open decisions for the owner

- **LS-24 (contract decision, no behavior change): cross-toolchain byte identity of generated normals is unpinned.** The builder computes normals with host `sqrt`/`acos` and the prototype CMake does not pin FP contraction (`-ffp-contract`), so the same source asset can produce different normal bytes under different compilers/FP environments, and a content-addressed cache keyed on those bytes is not portable across toolchains. Options: (a) pin FP semantics for the builder (contraction off, explicit math where practical) and quantize normals at serialization so byte identity is a contract; or (b) keep generation unpinned and make cross-platform cache tests semantic (compare decoded values with tolerance) instead of byte-exact. Owner to rule; nothing committed either way. The schema-version pin check from LS-25 (`tools/check_schema_version.sh`, CI) is in.
- **LS-54 future work (rejected-not-implemented, by ruling of this pass): payloads over `maxStorageBufferRange`.** The clean rejection now in place (see pass 6 notes) is the fix; splitting payloads across multiple descriptor bindings or moving the shaders to 64-bit addressing are the upgrade paths if assets ever outgrow the ~128 MiB core-minimum range. Not scheduled.

## Fixed 2026-10-05 (LS-01 page-packing regression)

- **BLOCKING REGRESSION (found 2026-10-05): LS-01's union-find LOD merge (1b8d59c) broke page packing for every scene beyond demo size. Fixed by repacking the LOD payload into final cluster-table order.** Root cause: `build_lod_metadata` stages `lod_geometry_payload` bytes in clodBuild callback order while the union-find materialization emits `lod_clusters` records in merged-record order; once a merge pulls non-adjacent callback groups into one record, the records keep stale callback-order offsets, and `build_lod_pages`' `[first cluster offset, last cluster end)` page spans wrap u32 arithmetic or exclude member payloads - `validate_resource` correctly fail-closed (`lod page payload range exceeds lod geometry payload` / `lod cluster payload falls outside owning page payload range`) on Massive City (2320 merged groups; exit 2), Stanford Dragon (1397), terrace 110x110/60x60, gltf_block 60x60; committed fixtures (terrace 36x28 = 16 merges and below) never crossed the onset. The fix takes the re-pack direction, NOT excluding cross-page records: `repack_lod_cluster_payloads` (builder_cluster.cpp) rebuilds `lod_geometry_payload` in final `lod_clusters` order after materialization and before `build_lod_pages`, rewriting every cluster's `geometry_payload_offset` - the same table-order-is-payload-order contract `append_reordered_cluster` already guarantees for the base payload - so pages are exact slices of the table-ordered payload in both domains. Hardening: both page builders verify per-page contiguity and sum spans in 64-bit (`narrow_payload_u32` rejects overflow) instead of assuming `[first, last end)`; `validate_resource` now checks the structural invariant per page (clusters back-to-back starting at the page offset, spans summing to the page size) and widens offset+size to 64-bit against the payload bounds. Regression-pinned fixture-free by `meridian_builder_tests` (new CMake target + CI step, no GPU/fixtures): repack rewrites permuted offsets to table order preserving every cluster's bytes, byte-for-byte no-op when orders agree, `build_lod_pages` must throw on non-contiguous order (the pre-fix code shipped a wrapped range here), and the full pack pipeline (repack -> pages -> page_index assignment) passes `validate_resource` across a page-cluster-limit matrix. Reverting `builder_cluster.cpp` to pre-fix main fails the test outright (undefined `repack_lod_cluster_payloads` at link); reverting only the page-range derivation to the old u32 `[first, last end)` arithmetic makes the built test fail at runtime (`FAIL: build_lod_pages did not reject non-contiguous cluster order`). Verified: dragon (1397 merged groups; was exit 2 at 1b8d59c, exit 0 at a16c9b2) and Massive City (2320) build exit 0 with clean validate; regenerated terrace 60x60 (38/39 merges) and gltf_block 60x60 (225) exit 0; all committed fixtures build; dump/trace/both committed replays pass; schema pin `version 6 consistent`.
